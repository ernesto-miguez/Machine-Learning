# Machine Learning

Colección de cuadernos Jupyter con ejemplos, ejercicios y proyectos de *machine learning*, análisis de datos e inteligencia artificial. El repositorio reúne materiales prácticos para explorar algoritmos, trabajar con datos y comprender distintas técnicas mediante código.

## Contenido

Entre los temas y ejemplos incluidos encontrarás:

- **Aprendizaje supervisado:** regresión lineal, clasificación, KNN, Naive Bayes, SVM, Random Forest y validación cruzada.
- **Aprendizaje no supervisado:** clustering con K-means y DBSCAN, clustering jerárquico y biclustering.
- **Redes neuronales y deep learning:** redes neuronales desde cero, GANs y ataques adversarios.
- **Análisis y preparación de datos:** NumPy, pandas, álgebra lineal, visualización y detección de anomalías.
- **Otros proyectos:** procesamiento del lenguaje natural, sistemas de recomendación, series temporales, análisis geoespacial, OCR y redes bayesianas.

## Cómo empezar

1. Clona el repositorio:

   ```bash
   git clone https://github.com/ernesto-miguez/Machine-Learning.git
   cd Machine-Learning
   ```

2. Abre el cuaderno que te interese con Jupyter Notebook, JupyterLab o Google Colab.

   Para usar Jupyter instalado localmente:

   ```bash
   pip install notebook
   jupyter notebook
   ```

3. Sigue las instrucciones y ejecuta las celdas del cuaderno. Las dependencias y los datos pueden variar entre notebooks; revisa las primeras celdas de cada uno para conocer los requisitos específicos.
